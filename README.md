# Kyklop für Android – APKs

Hier gibt es die fertigen Android-Versionen von **Kyklop**, einer Fernbedienung für
Saugroboter mit [Valetudo](https://valetudo.cloud).

Voraussetzung: **Android 12 oder neuer**. Handy und Saugroboter müssen im selben WLAN sein.

## Installieren und automatisch aktualisieren (empfohlen)

Mit [Obtainium](https://obtainium.imranr.dev) wirst du über neue Versionen benachrichtigt und
installierst sie mit einem Tipp.

1. Obtainium installieren (Download auf der Obtainium-Seite oder über F-Droid).
2. In Obtainium auf **App hinzufügen** tippen.
3. Als Quelle diese Adresse eintragen:
   ```
   https://github.com/scriptor-ger/kyklop_apk
   ```
4. **Hinzufügen** und anschließend **Installieren** tippen.

## Von Hand installieren

1. Unter [Releases](https://github.com/scriptor-ger/kyklop_apk/releases/latest) die Datei
   `kyklop-<version>.apk` herunterladen.
2. Datei antippen und die Installation aus dieser Quelle erlauben.
3. Für ein Update die neue APK einfach über die alte installieren – Einstellungen bleiben erhalten.

## Echtheit prüfen

Alle APKs sind mit demselben Schlüssel signiert. SHA-256-Fingerabdruck des Zertifikats:

```

```
